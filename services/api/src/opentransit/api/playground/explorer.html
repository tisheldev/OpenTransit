Departures from a stop

Routes

GET /v1/routes — give at least one of line, operator or stop; the API answers 422 without one.

Route detail and patterns

GET /v1/routes/{routeId} and …/patterns

Dated trip

GET /v1/trips/{tripRef}. Trip references come from departures or journey legs and are generation-scoped.

Plan a journey

POST /v1/journeys. Blank optional fields are omitted so server defaults apply.
