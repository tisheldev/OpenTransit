# Explicit ten-day comparison evidence

Snapshot of the previously recorded results, routing responses, manifests and
corpora before the 60-day-primary rerun. These are historical evidence, not
active configuration. The directory contains no executable runners.

The corpus snapshot already includes fixes made after the original routing
experiment. Each archived response's `case` is the authoritative record of
the coordinates and expectations actually queried. `compare_results.py`
uses those response cases when identifying confounded comparisons.

Primary ingest/routing results now live in `poc/results` and `poc/routing`.
